# 2 Year Anniversary — For Nivedita 💖

An interactive 3D WebGL anniversary website built with **HTML5, CSS3, and Three.js**.

### Features:
- 💎 **3D Faceted Crystal Diamond Heart**: Interactive cut-gemstone with high refraction, inner pulsating rose heart, and responsive mouse/touch rotation.
- 🌸 **Surrounding Cherry Blossoms**: Fluttering sakura petals and blooming cherry blossom flowers floating in 3D space.
- 🌌 **Cosmic Memory Vault Constellation**: Non-overlapping constellation of romantic milestones with luminous starlight beams.
- 📜 **Dual-Page Vintage Love Manuscript**: Open antique parchment book containing poetry and chronicles.
- 🎶 **Dual Audio Soundscape**:
  - `Vibe.mp3`: Romantic ambient vibe music with animated visualizer waves.
  - `Poem.mp3`: Synchronized narration that plays automatically when opening the poem and stops on close.
- 📱 **Mobile & Phone Optimized**: Responsive framing, one-line navigation, and touch controls.
